# iMeet

Мобильный каркас приложения знакомств iMeet с голосовым вводом на Android.

Стек первого этапа:

- React Native 0.88.1
- Expo SDK 58
- TypeScript
- Expo Router
- Zustand
- Android release APK для внутренней раздачи

## Запуск

```bash
npm install
npm run start
```

Затем выберите iOS или Android в Expo CLI. Для прямого запуска:

```bash
npm run ios
npm run android
```

## Проверки

```bash
npm run typecheck
npm run doctor
```

## Сборка Android

Expo используется как React Native-фреймворк; EAS не обязателен для локальной проверки.
При установленном Android SDK и JDK 21 можно собирать APK через Gradle:

```powershell
npx expo prebuild --platform android --no-install
cd android
.\gradlew.bat :app:assembleRelease
```

Локальный release APK создаётся в `android/app/build/outputs/apk/release/`.
Для внутренней раздачи используется профиль `manager` в `eas.json`:

```powershell
npx eas-cli@latest build --platform android --profile manager
```

Он выдаёт подписанный release APK с JS-бандлом, который запускается без Metro.
Профиль `development` оставлен для проверки JS-изменений через `npx expo start --dev-client`.

## Native layout and fonts

Экран использует `useSafeAreaInsets` и `useWindowDimensions`: размеры Figma 412×852
являются базовыми токенами, но не фиксированным размером приложения. Нижний Tab Bar
учитывает системный нижний inset, а статус-бар получает светлый режим.

`expo-glass-effect` используется только когда Liquid Glass доступен на iOS 26+.
На Android и старых iOS используется прозрачный градиентный fallback с верхней
подсветкой и границей — без WebView и без непрозрачной заглушки.

Figma использует Gilroy, Manrope и SF Pro. Лицензированные бинарные файлы в проекте
отсутствуют, поэтому временный fallback — системный SF Pro на iOS и Roboto на Android.
Интеграционная точка `src/theme/fonts.ts` подготовлена через `expo-font`. Для точного
рендера нужно предоставить:

- `Gilroy-Medium.ttf`
- `Manrope-Medium.ttf`
- `Manrope-SemiBold.ttf`
- `SFProText-Semibold.ttf`

## AI Conversation

Главный экран собран из локальных ассетов Figma в `assets/figma` и компонентов в `src/components/ai-conversation`.

Для голосового ввода нужен Android APK с `@naslukh/speech-rn@0.1.0`.

1. Установите APK и откройте iMeet. Приложение сразу готовит GigaAM и Supertonic, параллельно скачивая отсутствующие модели (~163 и ~139 МиБ), проверяя файлы и показывая прогресс. Загрузка не откладывается до нажатия кнопки разговора. Naslukh 0.1.0 не предоставляет отмену загрузки.
2. Когда загрузка завершится, выберите Supertonic F1 или системный TTS, нажмите «Начать общение» и разрешите доступ к микрофону. Произнесите фразу по-русски. После 2,5 секунды тишины или по кнопке «Закончить фразу» iMeet покажет распознанный текст и выберет ответ из локального сценария.
3. После окончания ответа iMeet автоматически включит микрофон. «Завершить разговор» прекращает прослушивание или озвучку. Последняя распознанная фраза и ответ остаются на экране.
4. Пока открыт экран разговора, приложение удерживает экран включённым. Для системной озвучки нужен русский голос движка Android. [Expo Speech](https://docs.expo.dev/versions/v58.0.0/sdk/speech/)

Анимация волны во время речи включается по событию VAD из Naslukh. Для реакции на громкость Naslukh нужен отдельный поток событий, например `onAudioLevel({ rmsDbFS })`, рассчитанный по уже захваченным PCM-кадрам и ограниченный примерно 10–20 обновлениями в секунду.

Для короткого подтверждения после 1 секунды тишины Naslukh нужен сигнал посреди той же реплики. Минимальный вариант — опция `backchannelSilenceMs: 1000` и событие `onVadPause({ sessionId, silenceMs })`, которое нативный модуль отправляет после приостановки захвата, сохраняя буфер реплики. Приложение произносит «Угу» и вызывает `resumeListenOnce(sessionId)` после окончания озвучки. Захват продолжится в рамках той же реплики до порога `vadMinSilenceSec: 2.5`. Тишину нужно измерять по захваченным кадрам, сбрасывая счётчик при возобновлении речи. Во время подтверждения микрофон приостановлен, поэтому слова пользователя в этот момент могут быть пропущены. В версии 0.1.0 работает только окончание реплики после 2,5 секунды тишины.

## Supertonic 3 INT8 на Android

В Android-сборке с локальным модулем `IMeetSupertonic` перед началом разговора можно выбрать «Supertonic 3 · F1» или «Системный TTS». Supertonic при первом запуске приложения скачивает около 139 МиБ. Модель закреплена на ревизии `cca5a0e6`. Приложение проверяет размер и SHA-256 каждого файла и сохраняет его в приватном кэше. Последующие разговоры используют проверенные локальные файлы. JNI и ONNX Runtime берутся из того же Maven-артефакта sherpa-onnx 1.13.5, что и для Naslukh. [Файлы модели](https://huggingface.co/csukuangfj2/sherpa-onnx-supertonic-3-tts-int8-2026-05-11/tree/cca5a0e6c96e1d2c720986bf7e75fcc81dee3ae4)

Чтобы проверить на OnePlus, установите Android-сборку с новым модулем, выберите F1 и начните разговор. Проверьте первую загрузку, повторное использование кэша без сети, произношение и прерывание через «Завершить разговор». При остановке во время синтеза уже начатый вызов ONNX завершается, а его результат отбрасывается. Во время воспроизведения остановка приостанавливает AudioTrack и освобождает его. Смена движка доступна между разговорами.

Метрики в `adb logcat -s IMeetSupertonic:I`. `initMs` измеряется отдельно от загрузки и проверки файлов, `synthesisMs` — время синтеза, `firstFrameMs` — время от запроса до первого обнаруженного кадра в Android AudioTrack. PSS суммарный для текущего процесса, `initPssDeltaKb` и `playbackPssDeltaKb` считаются относительно замера перед созданием модели.

В самом iMeet на OnePlus 7 Pro при совместно загруженных ASR и TTS получены синтез 3,37 с для короткого ответа и 5,36 с для среднего. PSS во время воспроизведения составил 629–644 МБ. Время от завершения речи до первого аудиокадра составило примерно 5,10 и 7,68 с соответственно; в него входит настроенная пауза VAD 3 секунды (в новой версии — 2,5 секунды). Повторный короткий разговор с F1 прошёл без сети.

## Размер Android APK

Прежний development APK `ad6b6684` весил 399,2 МБ (380,7 МиБ). Он содержал четыре ABI и отладочный код. Локальный release APK с одним ABI `arm64-v8a`, R8 и удалением неиспользуемых ресурсов весит 60,4 МБ (57,6 МиБ). Сборка запускается без Metro; модели GigaAM и Supertonic загружаются при открытии приложения и не входят в APK. Для устройства с другим ABI потребуется отдельная сборка. [Expo BuildProperties](https://docs.expo.dev/versions/latest/sdk/build-properties/)
